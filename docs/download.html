Chrome 확장프로그램 다운로드 · v0.3.5

  1. ZIP을 삭제하지 않을 위치에 압축 해제합니다.
  2. Chrome에서 chrome://extensions에 접속합니다.
  3. 개발자 모드를 켭니다.
  4. ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.
  5. manifest.json이 있는 폴더를 선택합니다.

업데이트

기존 폴더에 새 버전 파일을 덮어쓴 뒤 확장 관리 화면의 새로고침 버튼을 누르세요. 기존 확장을 삭제하거나 폴더를 옮기지 마세요. 자동 업데이트는 지원하지 않습니다.
