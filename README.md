# 그랑블루 검색 도우미

레이드와 조건을 클릭해 일본어·영문 검색어를 만드는 비공식 팬 도구입니다.

- 웹: `docs/` — 커스텀·환경설정 제외, 검색은 새 탭에서 열립니다.
- Chrome 확장: `gbf-search-builder-0.3.3.zip` — 커스텀·환경설정 포함.

## GitHub Pages 게시

이 폴더의 **내용물**을 `ww9999w/gbf-search-builder` 저장소에 올리세요.
Settings → Pages → Deploy from a branch → main /docs → Save.
게시 후 주소: https://ww9999w.github.io/gbf-search-builder/

## Releases

태그 `v0.3.3`으로 Release를 생성하고 ZIP을 첨부하세요. ZIP은 `docs/download.html`에서도 제공합니다.
Chrome 개발자 계정·스토어 등록은 필요하지 않습니다. 설치 안내는 웹 다운로드 페이지에 있습니다.

이미지는 기존 프로젝트 자산이며, 게임 관련 명칭·이미지의 권리는 각 권리자에게 있습니다.
코드의 공개 라이선스는 아직 지정하지 않았습니다.
