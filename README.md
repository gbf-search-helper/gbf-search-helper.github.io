# 그랑블루 검색 도우미

레이드와 조건을 클릭해 일본어·영문 검색어를 만드는 비공식 팬 도구입니다.

- 웹: `docs/` — 커스텀·환경설정 제외, 검색은 새 탭에서 열립니다.
- Chrome 확장: `gbf-search-builder-0.3.3.zip` — 커스텀·환경설정 포함.

## 이용하기

- [웹사이트 바로가기](https://ww9999w.github.io/gbf-search-builder/)
- [Chrome 확장프로그램 다운로드 및 설치 안내](https://ww9999w.github.io/gbf-search-builder/download.html)
- [최신 릴리스](https://github.com/ww9999w/gbf-search-builder/releases/latest)

## Chrome 확장프로그램 설치

1. 다운로드 페이지에서 ZIP을 받아 압축 해제합니다.
2. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.

확장프로그램은 커스텀 보스·검색조건(각 최대 6개)과 검색 열기 방식 설정을 지원합니다.
업데이트할 때는 기존 설치 폴더에 파일을 덮어쓰고 확장 관리 화면에서 새로고침하세요.
자동 업데이트는 지원하지 않습니다. 설치 폴더를 옮기거나 기존 확장을 삭제하면 저장된 설정을 유지하기 어려울 수 있습니다.

## 유지보수

정적 웹 소스는 `docs/`에 있습니다. GitHub Pages는 main 브랜치의 /docs 폴더에서 게시합니다.
확장프로그램 ZIP은 Releases와 웹 다운로드 페이지에서 제공합니다.

이미지는 기존 프로젝트 자산이며, 게임 관련 명칭·이미지의 권리는 각 권리자에게 있습니다.
코드의 공개 라이선스는 아직 지정하지 않았습니다.
